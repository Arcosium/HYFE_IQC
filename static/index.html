사용설명서 Manual

현재 로그인한 계정에 맞춰 열었습니다.

이 프로그램이 하는 일

유전 알고리즘으로 알파 후보를 만들고, WorldQuant BRAIN 에 시뮬레이션을 돌려 결과를 학습한 뒤, 제출 기준을 통과한 것을 제출합니다. 한 바퀴를 라운드라 부르며 멈출 때까지 계속 돕니다.

처음 할 일

  1. 운영 탭에서 시작을 누릅니다. 그게 전부입니다 — 조건을 안 걸면 기본값으로 돕니다.
  2. WQB 생체인증(Persona) 안내가 뜨면 링크를 눌러 한 번 완료해야 시뮬이 돕니다. 인증이 끝나면 창이 자동으로 닫히고 세션도 자동 저장됩니다 — '완료했습니다' 버튼은 자동 감지가 실패했을 때의 예비 수단입니다.
  3. 탐색 조건에 자연어나 필터 문법을 넣어 범위를 좁힐 수 있습니다. 재시작 없이 다음 라운드부터 적용됩니다.

제출 방식 — 자동 / 목록

운영 탭 제출 내역 카드 오른쪽 위에서 고릅니다.

  • 자동 제출 — 기준을 통과하면 곧바로 제출합니다. 사람이 볼 필요가 없습니다.
  • 목록에 추가 — 제출하지 않고 목록에만 쌓습니다. 직접 [제출] 을 눌러야 나갑니다. 제출은 되돌릴 수 없으니, 직접 확인하고 내보내려면 이쪽을 쓰세요.

WQB 가 거절한 제출은 일일 제출 예산을 쓰지 않습니다. 그래서 이 시스템은 "확실히 거절당할 알파"만 미리 막고, 나머지는 일단 내봅니다 — 통과 기준이 회전율·리전·delay 에 따라 갈려서 미리 계산해 거르면 통과할 알파를 놓치기 때문입니다.

탭 안내

  • 운영 — 실시간 로그, 제출 대기, 제출 내역. 제출 대기·제출 내역은 카드 제목을 눌러 접을 수 있고, 행을 클릭하면 알파 상세가 열립니다. 제출 내역이 10건을 넘으면 아래 쪽번호로 넘깁니다.
  • 전략 리서치 — 리서치 요청, 탐색 조건.
  • 진화 분석 — 세대별 궤적, 산점도(축 선택), 정향변이 학습, 리더보드. 리더보드는 각 열 아래 칸에 >1, >=1.2, <0.7 처럼 적으면 조건이 AND 로 걸립니다(회전율은 % 단위).

컨설턴트 계정에서 달라지는 것

  • 리전을 고를 수 있습니다. 탐색 조건에 region=GLB 처럼 적으면 그 리전으로 돕니다.
  • Power Pool 주간 테마가 자동 반영됩니다. 매주 WQB 지원 문서를 읽어 그 주 조건을 조건란에 넣습니다. 테마 경계는 UTC 자정(KST 09:00) 입니다.
  • 일일 제출 예산은 4건 이고, 리셋은 미 동부 자정(KST 13:00) 입니다. 테마 경계와 예산 리셋이 서로 다른 시계라, 그 사이(09:00~13:00)에 나온 새 테마 알파는 예산이 열릴 때까지 큐에서 기다립니다.
  • 끊긴 제출을 자동 회수합니다. 타임아웃·5xx 로 결과를 못 받은 제출을 다음 라운드에 다시 확인합니다.
  • 예산을 넘겨 제출 못 한 알파는 대기 큐에 쌓였다가, 예산이 리셋되면 (KST 13:00) 그날 한도(4건)를 채울 때까지 연달아 자동 제출됩니다. 단 제출 방식이 목록에 추가면 자동 제출하지 않습니다.

SuperAlpha (알파의 알파)

데이터필드가 아니라 이미 제출한 내 OS 알파들을 재료로 상위 신호를 만드는 경로입니다. 두 조각으로 씁니다 — 재료를 고르는 selection(회전율·롱숏 균형· 데이터필드 수·OS 시작일로 거른 뒤 최대 10개 선택)과, 고른 알파들의 통계를 하나로 합치는 combo(rank(stats.hold_value) 같은 식)입니다. 제출 이력이 쌓일수록 재료가 늘어 강해집니다.

⚠ super simulation 은 CONSULTANT 와 별개 권한입니다. 권한이 없으면 WQB 가 Not permissioned for super simulations 로 거절합니다 — WorldQuant 에 별도로 요청해야 합니다. 이 시스템의 실행 경로는 준비돼 있어서, 권한을 받으면 코드 수정 없이 바로 동작합니다. 자동 제출은 하지 않고 결과만 기록합니다(제출 판단은 사람이 합니다).

제출 기준 (컨설턴트)

고정된 하나의 컷이 아니라 두 갈래입니다.

  • 표준 — 회전율 20% 미만: Sharpe 1.58 이상(D1) / 2.69 이상(D0), Fitness 1.0 이상(D1) / 1.5 이상(D0)
  • 고회전(HT) — 회전율 20% 이상 + 비용 차감 후 Sharpe 가 기준을 넘으면 위 컷이 경고로 강등됩니다. 실측으로 Sharpe 1.06 짜리도 제출됐습니다.

공통: 회전율 1%~70%, 자기상관 0.7 미만(또는 상관 상대보다 샤프가 10% 이상 높으면 통과), 하위 유니버스 Sharpe 조건. 하위 유니버스 컷은 자기 샤프에 비례해 같이 올라갑니다 — 샤프만 밀어올리는 전략이 여기서 막힙니다.

일반 계정에서 달라지는 것

  • 리전은 USA 고정입니다. IQC 규칙이라 다른 리전으로는 경쟁할 수 없습니다. 조건에 다른 리전을 적어도 USA 로 되돌립니다.
  • delay 는 0 과 1 중에 고를 수 있습니다. 조건에 delay=0 또는 delay=1 로 적으세요.
  • 시뮬레이션은 컨설턴트와 똑같습니다. 같은 REST API 로 돌고 제출도 똑같이 시도합니다. (예전 화면에 "브라우저로 돌고 제출 안 함" 이라고 적혀 있었지만 사실이 아니라 2026-07-27 에 바로잡았습니다.)
  • 시뮬 전 사전 필터가 더 걸립니다. 문법 검사에 걸리거나, 이미 낸 알파와 너무 비슷하거나(유사도 0.7 이상), 구조가 겹치면 시뮬 자체를 건너뜁니다 — 한정된 시뮬 횟수를 아끼기 위해서입니다.
  • 주간 테마 자동 반영과 끊긴 제출 자동 회수는 동작하지 않습니다(컨설턴트 전용).

제출 기준 (IQC)

  • Sharpe — 회전율 20% 미만이면 1.58 이상(D1) / 2.69 이상(D0)
  • 회전율 20% 이상이면 고회전(HT) 경로로 컷이 완화됩니다
  • Fitness 1.0 이상(D1) / 1.5 이상(D0)
  • 회전율 1% 이상 70% 미만
  • 자기상관 0.7 미만
  • 하위 유니버스 Sharpe 조건 (자기 샤프에 비례해 움직임)
